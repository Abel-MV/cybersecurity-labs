# Cybersecurity Labs

This repository contains cybersecurity labs I have completed as part of my practical learning and BSc Cyber Security studies.

I use platforms such as TryHackMe, Hack The Box and CyberDefenders to practise technical skills, understand security concepts and gain experience with different tools and investigation methods.

My aim is to document what I did, explain the results and keep a record of what I learned from each lab.

## Objectives

- Develop practical cybersecurity skills through hands-on exercises.
- Improve my understanding of networking, Linux and Windows security.
- Practise reconnaissance, enumeration and vulnerability analysis.
- Learn how security weaknesses can be identified in authorised environments.
- Develop digital forensics and incident investigation skills.
- Document commands, findings and lessons learned clearly.

## Responsible Practice

All practical activities are carried out in authorised training environments.

Before publishing a writeup, I review the technical documentation, supporting evidence and relevant platform rules.

The writeups are intended to document my practical learning and technical understanding.

## Learning Approach

I aim to understand the tools and techniques I use rather than simply completing a challenge.

For each lab, I document the main steps, explain the results and identify what I learned.

I also try to distinguish between confirmed findings and potential security risks.
